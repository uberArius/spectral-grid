# Contributing

Bug reports, feature ideas and pull requests are welcome. Use English for public discussions and documentation.

For bugs, include app and Windows versions, GPU, audio output, reproduction steps and expected/actual behavior. Screenshots and diagnostics help. Remove personal information from attached logs and settings.

Build with `build.ps1` and run core tests before submitting code. Rendering, camera, window and particle changes also need `test-windows.ps1` on an interactive desktop. Add meaningful tests for behavior changes and keep unrelated edits separate.

Describe the problem, resulting behavior and validation in your pull request. Contributions are provided under Apache-2.0. Preserve third-party notices and identify changes to redistributed third-party files as required by their licenses.
