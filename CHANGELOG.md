# Changelog

## 1.0.0

First public release.

- Native Windows audio capture and GPU-rendered 3D spectrum history.
- Adjustable gravity, launch motion, one rebound and fixed lifetime color.
- Spectrum controls, high-frequency boost and optional smoothing.
- Scrolling up to 240 columns per second and rendering up to 240 FPS or unlimited.
- Camera tilt, pan, zoom and automatic in-plane rotation.
- Transparent, borderless, fullscreen and always-on-top modes.
- Persistent settings, core tests and Windows GPU integration checks.
- English interface and documentation, Apache-2.0 license and portable archives.
