# Third-party notices

| Dependency | Version | License | Upstream |
| --- | --- | --- | --- |
| Dear ImGui | 1.91.9b | MIT | https://github.com/ocornut/imgui |
| nlohmann/json | 3.11.3 | MIT | https://github.com/nlohmann/json |

CMake downloads versioned archives verified against SHA-256 hashes. Binary packages include the original texts as `licenses/DearImGui.txt` and `licenses/nlohmann-json.txt`. Source builds retrieve the notices with dependency sources.

Windows system components and the system-provided Segoe UI font are not bundled in source distributions. The app accesses them through Windows APIs.
